# SemanticOS

SemanticOS は、フォルダやタグなどの構造を一切使わず、「意味」で記憶を保存・検索できる外部記憶レイヤーです。  
人間にも AI にも使える、シンプルで軽量なセマンティックメモリです。  
AI のコンテキストリセットにも依存せず、あなたの知識を永続的に保持します。

## 特徴
- テキストを意味ベクトルとして保存
- キーワードではなく「意味」で検索
- タグ・フォルダなどの整理が不要
- どの AI モデルとも組み合わせて使える（AI 非依存）
- JSONL によるシンプルなストレージ
- 軽量で高速

## インストール
以下のコマンドで依存パッケージをまとめてインストールできます。

pip install -r requirements.txt

※ requirements.txt はこのリポジトリに含まれています。

## 使い方

### 1. テキストを保存する
python main.py save "ここに保存したいテキスト"

### 2. 意味検索する
python main.py search "検索したい内容"

## 哲学
SemanticOS は「構造に縛られない記憶」を目指しています。

- フォルダはいらない  
- タグもいらない  
- 整理もいらない  
- 必要なのは「意味」だけ  

あなたの外部脳として、知識をシンプルに保持し、いつでも取り出せるようにします。
